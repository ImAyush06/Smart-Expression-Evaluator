    User Manual & Help Center

    Learn about operator precedence, recursive factorials, and variable operations.

    Supported Operators

    • + Addition (e.g. 5 + 3 = 8)
    • - Subtraction (e.g. 10 - 4 = 6)
    • * Multiplication (e.g. 6 * 4 = 24)
    • / Division (e.g. 15 / 3 = 5, checks for zero-division)
    • % Modulo (remainder) (e.g. 10 % 3 = 1)
    • ^ Exponentiation (e.g. 2 ^ 3 = 8)
    • ( ) Parentheses to group calculations and force priority

    Special Functions

    • sqrt(x) Computes square root of x (e.g., sqrt(16) = 4)
    • factorial(x) Recursive evaluation (e.g., factorial(5) = 120, max input is 20)
    • percentage(x) Divides x by 100 (e.g., percentage(25) = 0.25)
    • pi, e Built-in constants (pi = 3.14159, e = 2.71828)

    History

    - Every calculation is saved to browser storage. You can check the details (including infix, postfix stack outputs, ID, and dates) in the **History** tab.
    - Search results refresh instantly as you type operators (e.g. *), keywords, or dates.
